# alok.dev

Personal portfolio for **Alok Kaintura** — Software Developer & Frontend Developer.

## Stack

- React 18 + TypeScript
- Vite
- Recoil
- Tailwind CSS v4
- Framer Motion
- React Router
- Lucide React

## Scripts

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Content

Portfolio copy is sourced from `Alok_Kaintura_Resume.pdf` via `src/data/*`. Update those files to change site content.
